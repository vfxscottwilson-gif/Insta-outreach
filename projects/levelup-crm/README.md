## If you are moving to a new PC
1. Back up the data first: `node database\backup-data.mjs` (in this folder).
2. Copy this whole folder (with `secrets\`) to the new PC, e.g. `F:\Github Repos\projects\levelup-crm`.
3. In the `install` folder open Command Prompt and run `INSTALL.cmd -Check` (changes nothing; shows what is missing).
4. Run `INSTALL.cmd` (double-click is fine). Wait for `RESULT: all good (Setup)`.
5. Sign in when asked: GitHub (`vfxscottwilson-gif`), Vercel (`npx vercel login`), Supabase token only if it stopped working. Details: SETUP-GUIDE.md section 5.
6. Run `INSTALL.cmd -Local` and open http://localhost:5173 to confirm it works.
