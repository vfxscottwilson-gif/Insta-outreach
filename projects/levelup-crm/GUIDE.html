01Get in today without the email code

This sets your admin password straight from your .env file. You type the password only into the file, never into chat.

  1. Open F:\Github Repos\projects\levelup-crm\app\.env in Notepad.
  2. Add a new line at the bottom, with your own password (8 or more characters): 
    NEW_ADMIN_PASSWORD=your-new-password
  3. Save the file and close Notepad.
  4. In the app's Terminal tab, run: 
    node "F:\Github Repos\projects\levelup-crm\app\scripts\set-admin-password.mjs"
  5. You should see Password changed. The script removes the password lines from .env by itself.
  6. Open the CRM (step 2) and log in with Khizarvfx@gmail.com and that password.

Or simply tell Claude "password added" after step 3, and it runs step 4 for you. Claude never sees the value.

03First-time setup inside the CRM

  1. Settings → Branding & apps: CRM name, logo (upload PNG or SVG), theme colour, default light or dark theme, and the left-side apps (show, hide, rename, change icon, reorder). The login page, buttons, charts and logo all follow the theme colour.
  2. Statuses and priorities: set the steps your work goes through (for example To Do, In Progress, Review, Done).
  3. Projects / Lists: one per client or show.
  4. Team (after step 4 is done): add each employee with name and email. They get a code by email, set their own password, and log in.

07How a day works

  • Admin (you): create and assign tasks with every field (title, description, time, deadline, status, priority), watch Dashboards and Reports, manage the Team and Settings, check the Audit log.
  • Employees: log in, see My Tasks, update status, track time with the timer, submit hourly and daily reports.
  • One session per account: logging in on a second device signs the first one out with a "Signed in elsewhere" message.
