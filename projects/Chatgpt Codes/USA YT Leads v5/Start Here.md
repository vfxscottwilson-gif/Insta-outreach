# Start Here - USA YT Leads v5
1. Create a GitHub repo and upload everything in this zip (keep the .github folder).
2. Repo Settings > Secrets and variables > Actions: add the secrets named in SECRETS-CHECKLIST.md.
3. Actions > USA YT Leads > Run workflow.
Change countries: config/settings.json ("countries"). Change niches: config/niches.json.
Full guide: START_HERE.md and UPGRADE_REPORT.md.
