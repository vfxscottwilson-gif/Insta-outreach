# 00 Start here: set up Scraper Tools on a PC

## A. Install
1. Copy the whole `scraper-tools` folder to the PC.
2. Double-click `install\INSTALL.cmd`. Click Yes if Windows asks.
3. Expected: a CHECKLIST of OK / SKIP lines. FAIL lines are explained in `04-TROUBLESHOOTING.md`.

## B. Keys
None. See `05-ACCOUNTS-AND-KEYS.md`.

## C. Use it
1. Pick a tool and its command from `SETUP-GUIDE.md` section 7.
2. Try 1-3 queries first, open the CSV in Excel, check it, then scale up.
